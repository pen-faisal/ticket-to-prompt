# Prompt rules

Copy this file to the root of your project as `PROMPT_RULES.md` and edit it.
The ticket-to-prompt skill reads it on every ticket, and its rules come before the skill's defaults.

## Defaults
- Default prompt mode: Detailed
- Ticket tool: Jira

## Code rules
- Follow existing patterns before creating new ones
- Do not add new libraries without approval
- Every change needs tests

## Review rules
- Changes to auth, payments or migrations need a second reviewer
